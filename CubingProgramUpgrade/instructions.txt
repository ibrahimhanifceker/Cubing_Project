Idea of upgrade:
- main upgrade lies in C++'s compilers already-installed optimization levels (absolutely insane speed up)
- checkInitial() now only checks the 32 affected small-sides instead of checking all 54
- file writing will auto compress the move sequences to include U2 and U' as a singular characters
in this case, u = U prime, r = R prime, X = U2, Z = R2
- Because the txt.file was written to have "\n" after every move sequence, the file reading process will read line by line (read a 
sequence until there's a new line character ) instead of taking the whole file into RAM and then finding orders from there.
--> less ram stress when calculating orders
- you can still use the CalculatingGroupOrdersFromAFile.cpp with just Us and Rs sequence and it probably will still be fast because the 
compilers optimization is so insane

This code depends alot on C++'s compiler pre-made optimization levels: (in this case I used -O2 which is considered safer but still
very quick)
If you put inside the terminal VSC's terminal this command:
    g++ -O2 -std=c++17 CalculatingGroupOrdersFromAFile.cpp -o CalculatingGroupOrdersFromAFile.exe
press enter then type this:
    .\CalculatingGroupOrdersFromAFile.exe
The compiler is going to optimize its compiling processes and is able to execute the file's commands more quickly

File writing took around 20 minutes
File reading took only around 10 minutes when used this optimization method
